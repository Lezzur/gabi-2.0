# GAIA — GABI 2.0 Platform

GAIA is the backend platform for GABI 2.0, a QR-based agricultural product authentication and farmer-rewards system for the Philippines. The monorepo contains a Next.js marketing website, a Next.js CRM for dealers and brand admins, an Expo mobile app for farmer-facing QR scanning, and shared packages for database types, Zod schemas, and cross-platform utilities.

## Quickstart

```bash
# Install Node 20 (via nvm or fnm)
nvm use

# Install dependencies
pnpm install

# Start all apps in dev mode
pnpm dev
```
